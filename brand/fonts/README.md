# Fonts

`texgyreheros-bold.otf` and `texgyreheros-regular.otf` are TeX Gyre Heros 2.004 (B. Jackowski and
J. M. Nowacki, GUST e-foundry), the Helvetica-style outlines of the wordmark. `glyphs.py` turns them into
SVG paths, so no shipped file embeds or needs the fonts.

They are released under the GUST Font License, which is the LaTeX Project Public License 1.3c or later
with one request (not a requirement) about renaming modified fonts. The licence text is
`GUST-FONT-LICENSE.txt` beside this file (from <https://tug.org/fonts/licenses/GUST-FONT-LICENSE.txt>).
The files here are unmodified.
